Pembaruan di Versi 1.4.4:

  • Perbaikan Gap MiniPlayer & Bottom Navbar: MiniPlayer kini terintegrasi langsung di atas Bottom Navigation Bar (jarak 4px rapat persis Spotify) tanpa ada celah konten kartu yang menyembul di antaranya.
  • Rilis Paket iOS iPhone (.ipa): Kini tersedia file McTify.ipa siap instalasi untuk iPhone/iPad via AltStore, Sideloadly, TrollStore, dan Scarlet dengan background playback audio iOS.
  • Bebas Regresi Berhenti di Detik ~50 (Full Song Uncapped): Stream MP4 itag 18 tanpa limit 1 MB dari YouTube agar seluruh lagu berdurasi 3-10 menit terputar mulus sampai akhir.
  • Play Awal, Transisi Lagu, Skip & Rewind Instan: Pre-warm Chunk 0 ke RAM, retry chunk tangguh di AudioProxyServer, dan AndroidLoadControl responsif.
📱 Panduan Instalasi di Android:
1. Klik tombol Download APK di atas.
2. Jika muncul konfirmasi "Tetap download", pilih izinkan.
3. Buka file APK dan tekan "Pasang" atau "Perbarui".

🍏 Panduan Instalasi di iPhone (iOS .ipa):
1. Via Sideloadly (Rekomendasi Paling Mudah & Cepat): Download Sideloadly di PC/Mac > Sambungkan iPhone via kabel > Drag file McTify.ipa > Masukkan Apple ID > Tekan Start.
2. Via AltStore: Buka AltStore di iPhone > Tab My Apps > Tekan tombol + > Pilih file McTify.ipa.
3. Via TrollStore (iOS 14.0 - 16.6.1 / 17.0): Download file .ipa langsung di Safari > Buka dengan TrollStore > Langsung terpasang permanen tanpa masa berlaku 7 hari.
4. Via Scarlet / Feather / LiveContainer: Buka aplikasi sideload > Pilih McTify.ipa > Pasang langsung dari iPhone tanpa PC.
